# Visuals Generation Guide

All figures are saved to `figures/` in the project root. LaTeX picks them up automatically via `\graphicspath{{figures/}}`.

---

## Quick regenerate everything

```bash
cd /home/abdul/Desktop/myosuite/custom_workspace

# 1. All CVAE ablation + training figures (13 figures for Ch 4)
/home/abdul/miniconda3/envs/MyoSuite/bin/python test/make_paper_figures.py

# 2. PCA dataset comparison (Ch 3 — original vs 3 augmentation methods)
/home/abdul/miniconda3/envs/MyoSuite/bin/python scripts/viz/pca_dataset_comparison.py

# 3. ID findings dashboard (Ch 5 — muscle activation, torques, synergies)
/home/abdul/miniconda3/envs/MyoSuite/bin/python scripts/viz/visualize_id_findings.py

# 4. Literature validation figure (Ch 5 — 18-check pass/fail)
/home/abdul/miniconda3/envs/MyoSuite/bin/python scripts/literature_validation.py \
  --gen-id-dir test/output/litval_I1/id \
  --output-dir figures/

# 5. Publication statistics figures (Ch 5 — group comparisons, correlations)
/home/abdul/miniconda3/envs/MyoSuite/bin/python scripts/publication_stats.py

# 6. CVAE validation / distribution comparison
/home/abdul/miniconda3/envs/MyoSuite/bin/python scripts/cvae_validation.py
```

## Notes

- All scripts use the conda env: `/home/abdul/miniconda3/envs/MyoSuite/bin/python`
- Run commands from `custom_workspace/` (project root), not from inside `latex/`
- `test/make_paper_figures.py` reads experiment outputs from `test/output/` — ensure the relevant experiment folders exist
- `literature_validation.py` requires ID output in `test/output/litval_I1/id/` (generated by `run_generated_pipeline.py`)
- The `figures/` folder is the single source of truth for LaTeX — `latex/main.tex` finds it via `\graphicspath{{../figures/}}`
- Never reference figures from `output/` or the project root directly in `main.tex`
- To compile: `cd latex && pdflatex main.tex` (run twice for cross-references, or use `latexmk -pdf main.tex`)
