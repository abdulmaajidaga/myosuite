# Visualization

Tools for rendering, analyzing, and interactively exploring motion capture and simulation data. All scripts are runnable standalone from the project root.

```bash
cd /home/abdul/Desktop/myosuite/custom_workspace
PYTHONPATH=. python src/visualization/<script>.py
```

## Scripts

### convert_mot2video.py

Renders a MOT joint-angle file to an MP4 video using MuJoCo offscreen rendering.

```bash
python src/visualization/convert_mot2video.py <model_xml> <input.mot> <output.mp4>

# Example
python src/visualization/convert_mot2video.py \
    models/model/myo_sim/arm/myoarm.xml \
    output/originals/mot/01_12_1.mot \
    output/originals/videos/01_12_1.mp4
```

**Input**: MOT file (joint angles) + MuJoCo XML model
**Output**: MP4 video (640x480, camera: azimuth=0, elevation=-20, distance=2.5)

### visualise_trc.py

Animates TRC marker trajectories in 3D. Displays all TRC files simultaneously with color-coded arm segments (shoulder-elbow-wrist).

```bash
python src/visualization/visualise_trc.py
```

**Input**: Auto-discovers all `.trc` files from `output/originals/trc/`
**Output**: Interactive 3D matplotlib window

**Key functions** (importable):
- `parse_trc(filepath)` -- Returns `(markers_dict, time_array)` where markers is `{name: (N, 3) ndarray}`
- `animate_all_trcs(file_list)` -- Creates multi-file 3D animation

### visualise_id_results.py

3-panel neuromechanical validation dashboard from inverse dynamics output:

1. **Mirror Test** -- Elbow torque vs summed flexor/extensor muscle activations
2. **Wrist Stabilization** -- ECRB vs FCR cocontraction pattern
3. **Muscle Heatmap** -- 12 key muscles activation over time (DELT, BIC, TRI, ECR, FCR, FCU)

```bash
# Auto-discovers first subject in output/originals/id/
python src/visualization/visualise_id_results.py

# Or specify a directory
python src/visualization/visualise_id_results.py output/originals/id/01_12_1
```

**Input**: `activations.csv` + `torques.csv` from an ID output directory
**Output**: `output/generated/plots/validation_dashboard.png`

### play_kinematics.py

Animates raw kinematic CSV data with Butterworth filtering and virtual joint computation. Shows upper arm, forearm, and wrist path trace in 3D.

```bash
python src/visualization/play_kinematics.py
```

**Input**: Healthy subject CSV (default: `data/kinematic/healthy/01_12_1.csv`)
**Output**: Interactive 3D matplotlib animation

**Key functions** (importable):
- `process_kinematic_data(filepath)` -- Reads MHH CSV with 2-row multi-level header
- `filter_data(df, cutoff=10, fs=100)` -- Low-pass Butterworth filter
- `calculate_virtual_joints(df)` -- Computes V_Wrist, V_Elbow, V_Shoulder from anatomical markers

### analyze_trunk_compensation.py

Compares trunk compensation between stroke and healthy subjects. Computes 10 metrics per file and correlates with FMA scores.

```bash
python src/visualization/analyze_trunk_compensation.py
```

**Metrics computed**:
- Trunk forward/lateral/vertical displacement and ROM
- Total 3D trunk displacement
- Trunk-to-wrist displacement ratio (key clinical metric)
- Shoulder protraction ROM
- Trunk rotation ROM
- Trunk peak/mean velocity
- Arm-trunk velocity correlation

**Input**: All CSVs from `data/kinematic/healthy/` and `data/kinematic/stroke/` + `output/scores.csv`
**Output**:
- `output/generated/plots/trunk_compensation_analysis.png` (12-subplot report)
- `output/generated/plots/trunk_compensation_data.csv` (full metrics table)

### fma_trend_analysis.py

Generates synthetic motions across the full FMA range and analyzes how biomechanical metrics correlate with impairment level. Validates that the CVAE produces clinically meaningful trends.

```bash
python src/visualization/fma_trend_analysis.py
```

**Process**: Generates 10 samples per FMA score (16 to 66, step 2) = 260 total motions, then computes 25+ metrics per sample.

**Metrics include**: ROM, peak/mean velocity, jerk, elbow-wrist coordination, path efficiency, trunk displacement, trunk-wrist ratio.

**Input**: Trained CVAE model (`models/cvae/cvae_cutoff_fma_best.pth` + scaler)
**Output**:
- `output/generated/plots/fma_trend_graphs.png` (16-subplot trend analysis)
- `output/generated/plots/fma_trend_summary.png` (top correlations + clinical severity boxplot)
- `output/generated/plots/fma_trend_data.csv` (all metrics)

### advanced_analysis.py

Comprehensive 10-output analysis pipeline. Generates complementary visualizations from raw motion capture data with phase-segmented analysis.

```bash
python src/visualization/advanced_analysis.py --dataset healthy
python src/visualization/advanced_analysis.py --dataset stroke
```

**Requires**: Phase index JSON files in `output/phase_indices/` (generated by `phase_selector.py`).

**10 outputs**:
1. Feature heatmap (normalized)
2. Parallel coordinates plot
3. Time-normalized velocity profiles (Pick/Drink/Place phases)
4. 2D wrist trajectories (X/Y/Z, 5x5 grid)
5. 3D arm postures at key events
6. Phase-wise boxplots (Duration, PeakVel, PathLen)
7. 3D phase paths (shoulder-relative, color-coded)
8. Coordination cyclograms (Shoulder elevation vs Elbow flexion)
9. Advanced feature boxplots (ROM, trunk, straightness, smoothness)
10. Efficiency scatter (Straightness vs Efficiency, colored by trunk compensation)

**Input**: CSVs from `data/kinematic/{healthy,stroke}/` + phase indices JSON
**Output**: 10 PNG files to `output/analysis/{healthy,stroke}/`

### interactive_viewer.py

Real-time CVAE motion generation with live 3D visualization. Adjust FMA score via slider and instantly see generated arm movement with trunk compensation.

```bash
python src/visualization/interactive_viewer.py
```

**Controls**:
| Control | Action |
|---------|--------|
| FMA Slider (0-66) | Change impairment level, regenerates motion |
| Frame Slider (0-99) | Jump to specific frame |
| Pause/Play | Toggle animation |
| Reset | Restart from frame 0 |
| New Sample | Generate a new stochastic sample (same FMA) |

**Display**:
- Left panel: 3D arm animation (upper arm, forearm, wrist vector, trajectory trace)
- Right panel: 2D wrist trajectory (Y-Z reach-height plane)
- Info bar: arm lengths, wrist position, trunk displacement

**Input**: Trained CVAE model + scaler
**Output**: Interactive matplotlib window (no files)

### phase_selector.py

Interactive GUI tool for manually labeling motion phases. Displays a synchronized 3D arm animation alongside a velocity profile where users click to mark 5 keypoints.

```bash
python src/visualization/phase_selector.py --dataset healthy
python src/visualization/phase_selector.py --dataset stroke
```

**Phase sequence**: Rest -> Pick -> Drink -> Place -> Rest (5 keypoints)

**Controls**:
| Action | Effect |
|--------|--------|
| Left-click on velocity plot | Add keypoint (snaps to nearest velocity minimum) |
| Right-click | Remove last keypoint |
| `d` key | Delete last keypoint |
| `Enter` | Accept and move to next file |

**Input**: CSVs from `data/kinematic/{healthy,stroke}/`
**Output**:
- JSON with indices per file (auto-saved after each file):
  - `output/phase_indices/manual_phase_indices.json` (healthy)
  - `output/phase_indices/stroke_manual_phase_indices.json` (stroke)
- Summary PNG grid showing all velocity curves with selected points
